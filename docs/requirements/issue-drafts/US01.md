## 用户故事

作为ChangeScope 团队成员，我想通过 GitHub 身份认证进入系统，并获取本人获准访问的项目范围，以便不必额外维护课程项目密码。

## 验收标准（Given / When / Then）

- **Given**：用户尚未登录且 GitHub OAuth 可用。
- **When**：用户完成 GitHub 授权。
- **Then**：系统创建有效会话，仅展示其获授权项目；取消授权时不创建会话。
