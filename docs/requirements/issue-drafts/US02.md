## 用户故事

作为质量管理员，我想选择一个当前账户有访问权限的 GitHub 仓库作为分析对象，以便确定分析范围并限制越权读取。

## 验收标准（Given / When / Then）

- **Given**：质量管理员已登录并具备仓库访问许可。
- **When**：选择仓库并确认。
- **Then**：系统记录仓库标识、授权范围及操作者；无权限仓库被拒绝。
