## 用户故事

作为开发人员，我想按授权仓库浏览 PR 基本信息与当前版本，以便快速定位需分析或需审查的变更。

## 验收标准（Given / When / Then）

- **Given**：用户有仓库查看权限且 PR 数据可用。
- **When**：打开 PR 列表。
- **Then**：显示 PR 编号、标题、状态和最新 head SHA，并阻止查看未授权仓库。
