## 用户故事

作为开发人员，我想选择 PR 生成与其最新提交绑定的风险评估结果，以便在审查前识别需要关注的修改。

## 验收标准（Given / When / Then）

- **Given**：PR 和历史快照可用，用户有分析权限。
- **When**：对某个 PR 发起分析。
- **Then**：系统生成带 PR head SHA、历史快照、规则版本的分析任务及结果或明确失败信息。
