## 用户故事

作为代码审查员，我想找出与 PR 修改文件有历史共变更关系的其他文件，以便降低遗漏潜在受影响文件的可能性。

## 验收标准（Given / When / Then）

- **Given**：历史共变更索引已建立且 PR 有修改文件。
- **When**：打开关联文件分析。
- **Then**：显示未在本次PR中修改的关联文件、关联比例及共同提交次数，低于阈值者不展示。
