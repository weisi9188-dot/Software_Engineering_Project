## 用户故事

作为开发人员，我想比较同一 PR 不同 head SHA 的风险分析结果，以便知道修改后关注点是否发生变化。

## 验收标准（Given / When / Then）

- **Given**：同一 PR 有两个不同提交版本的分析结果。
- **When**：选择两个版本比较。
- **Then**：系统并列展示风险分数、指标差异及各版本的分析快照。
