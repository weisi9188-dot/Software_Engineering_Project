# [Story][US12] 查看个人 PR 风险记录

> **状态：需求假设 / 待真实访谈核实。不得以草稿冒充已完成调研或已创建Issue。**

- 类型标签：`story`
- 优先级：`P1`（建议，待团队确认）
- 建议责任分工：C（前端/交互）（**不是GitHub已分配的Assignee**）
- 关联需求：`FR-12`
- 关联用例：`UC12`
- 计划测试：`TC-UC12-01`
- 真实调研证据链接：**【待填写：访谈纪要/问卷/评审中的具体段落】**

## 用户故事

作为开发人员，我想查看自己可访问 PR 的历史风险分析记录，以便方便追踪整改与复查过程。

## 验收标准（Given / When / Then）

- **Given**：用户已登录并有相关 PR 权限。
- **When**：打开个人分析历史。
- **Then**：按时间展示本人相关 PR、分析状态、版本和结果链接。

- 访谈对象与受访者角色：【待填写】
- 调研日期与原话位置：【待填写】
- 发现的新需求或删改意见：【待填写】
- 拟发布的GitHub Issue链接：【待创建】
- 人工评审人及结论：【待填写】
