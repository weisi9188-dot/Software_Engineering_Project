## 用户故事

作为代码审查员，我想将可访问且待审查的 PR 按风险提示值排序，以便把有限审查时间优先用于值得关注的变更。

## 验收标准（Given / When / Then）

- **Given**：当前项目存在可见的待审查 PR 与对应风险结果。
- **When**：进入待审查视图。
- **Then**：按分数排序并展示分数时间、无数据标记及规则版本。
