## 用户故事

作为代码审查员，我想对指定 PR 获取符合约束条件的候选审查员排序，以便辅助寻找具有相关代码经验的人员。

## 验收标准（Given / When / Then）

- **Given**：PR 已分析且有可访问的候选人信息。
- **When**：请求审查员推荐。
- **Then**：返回候选人排序，明确排除 PR 作者及不具备权限的人员。
