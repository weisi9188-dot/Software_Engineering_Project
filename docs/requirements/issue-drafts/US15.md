## 用户故事

作为质量管理员，我想检查某候选人的代码经验和工作负载依据，以便验证推荐是否合理而非盲从排序。

## 验收标准（Given / When / Then）

- **Given**：指定 PR 已存在推荐结果。
- **When**：打开候选人的匹配依据。
- **Then**：显示与 PR 关联的历史经验、活跃度和负载信息或明确数据不足。
