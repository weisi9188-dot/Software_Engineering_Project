## 用户故事

作为质量管理员，我想汇总审查员的反馈类别和样本数量，以便判断哪些风险提示可能需要改进。

## 验收标准（Given / When / Then）

- **Given**：项目存在可访问的人工反馈。
- **When**：筛选时间范围并查看统计。
- **Then**：展示有效、无效、待确认的数量和分母，禁止无样本时显示误导性比例。
