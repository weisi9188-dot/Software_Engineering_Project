## 用户故事

作为质量管理员，我想确保未授权用户无法读取其他项目数据或修改规则，以便保护代码元数据及配置。

## 验收标准（Given / When / Then）

- **Given**：存在无权限账户与需保护的仓库/规则。
- **When**：尝试访问受保护接口并进行越权写入。
- **Then**：全部请求被拒绝（401或403），数据库无越权写入，响应与日志均不暴露 GitHub 凭证。
