## 用户故事

作为代码审查员，我想GitHub 暂时不可用时仍能查看已完成的缓存报告，以便在外部故障期间保留必要的审查信息。

## 验收标准（Given / When / Then）

- **Given**：已有缓存分析报告，模拟 GitHub API 超时或持续返回5xx。
- **When**：查看已有报告并尝试新数据同步。
- **Then**：缓存报告可查看且标注更新时间；同步任务在10秒内显示可重试的失败状态，服务恢复后可手动重试成功。

## 评审关注

请组员确认数值目标、测试环境与约束是否现实；正式指标须先经需求评审，后通过测试实测验证。未满足时如实记缺陷，不伪造通过记录。
